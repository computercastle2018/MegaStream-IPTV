# MegaStream — Direct APK downloads

Signed release builds, kept here for direct download from the repository.

| File | Use it for |
|---|---|
| [`MegaStream.apk`](MegaStream.apk) | **Universal — works on every device (recommended)** |
| [`MegaStream-arm64.apk`](MegaStream-arm64.apk) | Modern 64-bit devices (smaller) |
| [`MegaStream-armv7.apk`](MegaStream-armv7.apk) | Older 32-bit devices (smaller) |

## Download

Open a file above and press **Download**, or fetch it directly:

```
https://github.com/computercastle2018/MegaStream-IPTV/raw/main/apk/MegaStream.apk
```

The same builds are attached to every [GitHub Release](https://github.com/computercastle2018/MegaStream-IPTV/releases), and this permalink always resolves to the newest published one:

```
https://github.com/computercastle2018/MegaStream-IPTV/releases/latest/download/MegaStream.apk
```

## Notes

- All builds are signed with the official MegaStream release certificate
  (SHA-256 `cb:24:35:eb:…:8a:c0:e4`). Installing a build signed with a different
  key over an existing install fails — uninstall first if that happens.
- These files track the latest release; refresh them whenever a new version ships.
